# Security policy

## Scope

TCTC Guardian Z797 is a narrowly scoped defensive utility for the analysed TCTC / Z797 chain. Security reports should concern this repository, its detection logic, its telemetry handling, its remediation safeguards, or its release process.

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature for this repository when it is enabled. Include:

- affected release or commit;
- Windows edition/build and Python version;
- safe, reproducible steps;
- expected and actual behavior;
- minimal, redacted logs or test fixtures.

Do not attach live malware, extracted payloads, shellcode, memory dumps, packet captures, credentials, access tokens, or unrelated personal data. Do not contact suspected campaign infrastructure as part of a report.

## Response expectations

This is a community project with no guaranteed response-time SLA. Reports will be reviewed as maintainer availability permits. Please allow maintainers to investigate and prepare a fix before public disclosure.

## Supported release

The initial public release is `v1.0.0`. Report whether an issue also reproduces on the latest published release.
